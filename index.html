S1

Foundations and reset

My implementation of a compact reset which retains a predictable starting point and native features.

My decisions:

  • box-sizing: border-box makes the widths include both padding and border making the component sizing easier to predict.
  • The default margins were removed from headings and paragraphs so spacing cna come from the global spacing tokens.
  • Media assets are constrained to their container to avoid horizontal overflow issues.

My reset is selective, keeping the native form behavior. The stylesheet adds a visible keyboard-focus outline.

Font source, license and fallback

The specimen does not utilize any downloaded webfonts nor does it include any font files. Instead, it uses standard system-installed fonts from the Georgia and Arial font family. The CSS uses font weights 400, 600, and 700 for regular and bold styles. Italics are not used. As a fallback, if Georgia and Arial are unavailable on the system rendering the website, Times New Roman and Helvetica are requested instead, with a generic serif and sens-serif in the event those fonts are also not installed.

The hero is sized using clamp() to scale between a minimum and maximum. The body text uses a capped measure/line length for readability.
